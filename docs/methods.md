# Methods and evidence

## Data and labels

The input source is the [DTU Computational Materials Repository cubic-perovskite database](https://cmr.fysik.dtu.dk/cubic_perovskites/cubic_perovskites.html), recorded locally as an ASE/SQLite file. The CMR site states CC BY-SA 4.0 terms for its databases; those terms do not license MEIDNet source or checkpoints. `scripts/prepare_cmr_dataset.py` retains 18,928 non-reference five-atom records from 19,369 source rows and excludes 441 reference records. It carries source IDs, source-to-parser site permutations, species, and quoted CIF text into the export. No relaxation or stability filter is applied. The full generated CSV/CIF tree is local data, not included in this repository.

The required labels are `[heat_all, dir_gap]` in that order. `heat_all` copies CMR `heat_of_formation_all` in eV/atom; it is a finite-reference-pool DFT formation/stability quantity, not an elemental formation enthalpy or energy above a convex hull. Some values cannot be reconstructed exactly from the present reference rows, and correspondence with the pretrained MEIDNet checkpoint's original `heat_all` semantics is unresolved. `dir_gap` copies the direct GLLB-SC gap in eV, not the indirect gap. Its 18,193 zero values remain zeros rather than inferred metal labels. The export has 13,520 mixed-anion and 5,408 single-anion records. Only 280 fit the earlier single-anion generation vocabulary; that is a vocabulary count, not a dataset size or physical-validity count.

Records were grouped by reduced composition and assigned with seed 42 to 15,143 TRAIN, 1,893 validation, and 1,892 final-test rows. The 20-record initial audit panel was selected from validation, not the final test. These are newly constructed splits, not the original MEIDNet paper's memberships. Pretrained-checkpoint training overlap is unknown. The recorded [split summary](experiments_summary.md#dataset-and-split) and [conversion manifest path described by the code](../scripts/prepare_cmr_dataset.py) give the available provenance; source database and export manifests are local inputs when supplied. A historical repository-wide test read the final-test CSV for split accounting, although the recorded model runs did not perform final-test inference.

## Decoder interfaces and policies

Frozen MEIDNet supplies two projected common latents. The representation cached for diffusion is `z_joint = (z_c_common + z_p_common) / 2`; each branch is normalized after projection, but their average is not normalized again. Raw `[heat_all, dir_gap]` enters the frozen property encoder. The upstream reconstruction path can receive a reference structure's coordinates and center. The later reference-free adapter instead supplies the same universal 20-slot coordinate tensor and fixed five-site center to every request, as specified in the required local template input manifest. “Reference-free” therefore does not mean zero coordinates. The upstream reconstruction and generation decoder interfaces remain distinct.

The first 20-reference [decoder audit](experiments_summary.md#decoder-inputs) separated raw reference-assisted reconstruction, zero-coordinate reference-free decoding, latent controls, and output projected through the legacy rules. Removing reference geometry worsened occupied-site A/B evidence; the recorded mean raw NLL difference was 32.3852 nats/site, with a 95% whole-group interval of [26.9215, 38.0224]. Reference-assisted structures matched in 18/20 cases at `StructureMatcher(scale=False)`; reference-free raw geometry matched 0/20. Projected success is a different question, because the legacy path discards learned coordinates and lattice in favor of an ideal template and ionic-radius cell.

The informed [template follow-up](experiments_summary.md#fixed-template-decoding) used the fixed input tensor. Within the 20-reference panel, raw joint-latent `scale=False` matches rose to 16/20 under that fixed geometry, but only 2/20 source references could pass the unchanged charge and projection rules. Its nitride output space was empty under the enumerated frozen tolerance and octahedral constraints. These are interface and rule findings, not a diffusion or independent materials-quality result.

The later [multifamily study](experiments_summary.md#mixed-anion-policies) distinguished source catalogue coverage from learned recovery and proposal acceptance. It used a deterministic 384-record validation panel, a 64-record proposal panel, and a separate revisit of the earlier 20 references. Rare positive-gap strata were deliberately overrepresented, so the panels are not population samples. The policy source `scripts/multifamily_policies.py` is frozen because its hash enters compatibility checks.

| Policy | Source catalogue scope | Actual distinction |
|---|---:|---|
| MF_P0 | 40 projected legacy-oracle exportable; 280 in old source vocabulary | Unchanged legacy route and full legacy vetoes |
| MF_P1/P2 | 280 source eligible after removing old vetoes | Isolate old-rule and cell choices within the old role pools |
| MF_P3 | 5,408 source eligible | Global TRAIN-derived roles but one homogeneous X species |
| MF_P4 | 18,928 source eligible | Global TRAIN-derived A/B/X roles with independent X1/X2/X3 sampling |

These source-coverage counts are not neural output success rates. `DECLARED_DOMAIN` can impose a family anion; `LEARNED_ANION` samples from TRAIN-derived role support. The diffusion arm uses MF_P4, `LEARNED_ANION`, temperature 1.25, fixed A/B/X1/X2/X3 logit slots, and no per-request family mask, charge veto, or reference-species input. Its learned cell is based on `20 * lat_out[:3]`, a mean-length cubic metric, and the fixed output template, not the legacy radius cell. Raw head values, projected geometry, minimal acceptance, and CIF serialization are separate outcomes. In particular, a CIF write failure is recorded separately and need not undo a preceding minimal-acceptance flag. Minimal site/cell/periodic-overlap acceptance says nothing by itself about stability, property attainment, novelty, or synthesis.

## Conditional latent diffusion

TRAIN-only featurewise means and population standard deviations scale joint latents and conditions separately: `u = (z_joint - mean_z) / std_z` and `c = ([heat_all, dir_gap] - mean_y) / std_y`. A positive standard-deviation floor is saved with the scaler. Generated `u` is inverted before frozen decoding. Caches retain stable material IDs, source metadata, split, raw conditions, complete/partial status, and fingerprints; final-test caching requires an explicit opt-in. A capped CPU cache and a future full-data cache define different coordinate systems. Changing cache membership, representation, or scalers requires a fresh denoiser rather than checkpoint continuation.

The recorded denoiser is a 128-dimensional epsilon-prediction residual MLP with width 256, four blocks, expansion two, LayerNorm, SiLU, and sinusoidal timestep embeddings. FiLM scale/shift context reaches each block. A separate presence bit distinguishes an absent condition from the real standardized pair `[0, 0]`. Only denoiser parameters enter AdamW. The CPU configuration uses 0.10 condition dropout and a 1,000-level, zero-indexed linear-beta schedule from 0.0001 to 0.02. For standard Gaussian epsilon, the forward marginal and objective are:

```text
u_t = sqrt(alpha_bar_t) * u_0 + sqrt(1 - alpha_bar_t) * epsilon
L = mean((epsilon - epsilon_theta(u_t, t, c))^2)
```

Generation uses deterministic 20-step DDIM (`eta=0`) on the same trained schedule, including levels 999 and 0 and a final clean endpoint. Guidance is `epsilon_uncond + s * (epsilon_cond - epsilon_uncond)`. Guidance zero is the same conditional denoiser with its condition suppressed, not a separately trained model. This implementation does not use ancestral DDPM sampling, latent clipping, or reference latents at generation. The Gaussian objective follows [Ho, Jain, and Abbeel](https://arxiv.org/abs/2006.11239); the deterministic sampler follows [Song, Meng, and Ermon](https://arxiv.org/abs/2010.02502).

The 24 September 2026 CPU record used 1,024 stratified TRAIN and 128 stratified validation cache rows, a separate 16-example/200-update fixed-corruption diagnostic, then a fresh 500-update ordinary smoke with batch 32, seed 0, learning rate `2e-4`, weight decay `1e-4`, and clip norm 1. The fixed-bank MSE changed from about 1.11535 to 0.52792; the final noisy-latent-as-epsilon comparator was about 0.53919. The separate overfit diagnostic demonstrates gradient flow and memorization only. Historical CPU continuation records report exact state equality for six uninterrupted updates versus a 2+4 resume on one environment. None of this implies cross-device bitwise equality or scientific generation quality.

The first generation panel and its paired-metric replay, described in the [experiments summary](experiments_summary.md#conditional-latent-diffusion), use the same checkpoint, eight TRAIN-supported requests, eight attempts per request and method, seeds, and weights. They are one panel plus a replay, not two independent studies. The replay added conditional-versus-guidance-zero latent L2 after the first panel was inspected; its median was 2.107. The saved ledgers account for all 256 method/request/attempt rows, including 16 diffusion lattice rejections. The conditional DDIM median latent norm of 78.985 versus 0.943 for TRAIN-cache joint latents is the main quality warning. The empirical comparator samples among the 16 nearest TRAIN-cache property pairs and can select the request's own example. It is not a held-out prediction test. The original upstream optimized-latent baseline was not run in this comparison.

## Local inputs and recorded results

[The experiments summary](experiments_summary.md) brings together the split audit, frozen forward check, decoder and template studies, mixed-anion policies, and CPU diffusion results from 23 and 24 September 2026.

Caching and generation use the [template input manifest](../reports/template_reachability/input_manifest.json) and [training-role support JSON](../reports/multifamily_rule_relaxation/training_support.json) included under `reports/`. Both entry points accept other locations through `--template-manifest` and `--training-support`. The manifest contents must match the fingerprints used by the caches and checkpoints. Denoiser training reads the completed caches instead.

The JSON manifests, CSV tables and example CIFs are included under `reports/`. The three decoder audit entry points also check original protocol Markdown and, in the template and multifamily audits, preceding report Markdown. Those Markdown inputs must be supplied locally at the paths defined in the scripts; this summary does not replace them. In these audit commands, `--report-dir` controls outputs, not the fixed input locations. The template audit also requires an earlier Git commit that is unavailable in the public branch. Tests that depend on these assets need the corresponding inputs.

The full CMR export, raw database, CPU latent snapshots, denoiser checkpoint, original MEIDNet paper data and split membership, and independent property/stability measurements are absent from the public tree. The label/checkpoint relationship and pretrained training overlap remain unresolved. `configs/diffusion/gpu_train.json` records an unexecuted full-data plan, not a completed GPU result. The upstream snapshot's README advertises MIT and its package metadata names MIT, but no separate license text or checkpoint redistribution permission was found in the supplied snapshot; no new blanket license is assigned here.
